# 选手评分系统完整指南

## 评分系统概述

FlyEsports使用**双重评分系统**来全面评估选手：

### 1. **总评分（ELO系统）**
- **范围**：0-5000
- **标准起始分**：1200
- **用途**：反映选手整体实力，用于匹配和排名
- **计算方式**：基于比赛胜负，使用ELO算法动态调整

### 2. **六维度评分（百分制）**
- **范围**：0-100（每个维度独立）
- **默认起始分**：50
- **用途**：展示选手具体能力特长，用于战队招募参考
- **计算方式**：基于比赛中的详细表现数据
- **六个维度**：KDA、伤害、经济、视野、资源控制、团战

**两者关系：**
- 总评分决定选手在排行榜的位置和匹配对手
- 六维度评分提供选手能力的细节画像
- 两个系统独立运作，互不影响

## 新注册选手如何进入评分系统

### 1. **用户注册选手档案**

当用户通过API `/api/v1/player/register` 注册选手时，系统会：

#### 步骤1：填写基本信息
```json
{
  "user_id": "1",
  "region_id": "region_1",
  "player_name": "玩家昵称",
  "summoner_name": "召唤师名称",
  "position": "MIDDLE",
  "rank_tier": "GOLD",        // 可选：LOL段位
  "rank_division": "II",      // 可选：段位细分
  "league_points": 75,        // 可选：胜点
  "description": "个人简介"
}
```

#### 步骤2：系统计算初始评分

系统会根据用户提供的**英雄联盟段位**自动计算初始评分：

| LOL段位 | 基础评分 | 段位细分加成 | LP加成 | 最终评分范围 |
|---------|---------|-------------|--------|--------------|
| 未排位 | 1200 | - | - | 1200 |
| IRON (黑铁) | 600 | 0-150 | 0-50 | 600-800 |
| BRONZE (青铜) | 800 | 0-150 | 0-50 | 800-1000 |
| SILVER (白银) | 1000 | 0-150 | 0-50 | 1000-1200 |
| GOLD (黄金) | 1200 | 0-150 | 0-50 | 1200-1400 |
| PLATINUM (铂金) | 1450 | 0-150 | 0-50 | 1450-1650 |
| EMERALD (翡翠) | 1700 | 0-150 | 0-50 | 1700-1900 |
| DIAMOND (钻石) | 1950 | 0-150 | 0-50 | 1950-2150 |
| MASTER (大师) | 2200 | - | 0-50 | 2200-2250 |
| GRANDMASTER (宗师) | 2500 | - | 0-50 | 2500-2550 |
| CHALLENGER (王者) | 2800 | - | 0-50 | 2800-2850 |

**段位细分加成规则：**
- IV（4段）：+0分
- III（3段）：+50分
- II（2段）：+100分
- I（1段）：+150分

**LP加成规则：**
- 每1点LP增加0.5分评分，最高50分

**示例计算：**
```
段位：Gold II，LP：75
基础评分：1200
段位加成：100（II段）
LP加成：37.5（75 × 0.5）
初始评分：1337.5
```

#### 步骤3：创建选手档案

系统自动创建选手档案，包含：
- **初始总评分**：根据段位计算的评分（ELO系统，范围0-5000）
- **六维度评分**：初始时所有维度均为**50分**（百分制，范围0-100）
  - KDA（击杀/死亡/助攻）：50/100
  - Damage（伤害输出）：50/100
  - Economy（经济发育）：50/100
  - Vision（视野控制）：50/100
  - Objective（资源控制）：50/100
  - Teamfight（团战表现）：50/100
- **置信度**：0.5（50%，最低置信度）
- **比赛场次**：0
- **合同状态**：FREE（自由选手）

**重要说明：**
- **总评分**使用**ELO系统**（0-5000范围），反映选手的整体实力
- **六维度评分**使用**百分制**（0-100范围），反映各项具体能力
- 两者是独立的评分系统，不要混淆

---

### 2. **通过比赛提升评分**

选手注册后，需要参加比赛才能更新评分：

#### 方式1：参加赛区赛季
1. 加入或创建战队
2. 战队报名参加赛季
3. 参加比赛
4. 上传比赛数据（通过Riot API或手动录入）

#### 方式2：参加自定义比赛
1. 组织者创建比赛房间
2. 选手加入比赛
3. 完成比赛后上传数据

---

### 3. **评分更新机制**

每场比赛结束后，系统会自动更新选手评分：

#### ELO评分计算公式
```
新评分 = 当前评分 + K系数 × (实际得分 - 预期得分)

其中：
- K系数：根据比赛场次和置信度动态调整（16-64）
- 实际得分：胜利=1.0，失败=0.0
- 预期得分：基于双方评分差计算（0.0-1.0）
```

#### 置信度提升
- 每场比赛后置信度提升 **+0.01**
- 最高置信度：**0.95**（95%）
- 高置信度选手的评分波动更小（K系数降低）

#### 定级赛机制
前**10场比赛**为定级赛：
- K系数加倍（评分变化更大）
- 置信度快速提升
- 帮助新选手快速达到真实水平

#### 六维度更新
系统会根据比赛中的表现数据分析选手的六维度能力（**0-100百分制**）：
- **KDA维度**：基于击杀/死亡/助攻比率（0-100分）
- **伤害维度**：基于输出伤害数据（0-100分）
- **经济维度**：基于金币获取和经济领先（0-100分）
- **视野维度**：基于插眼/排眼数据（0-100分）
- **资源控制**：基于击杀大龙/小龙/先锋等（0-100分）
- **团战维度**：基于团战参与率和团战输出（0-100分）

**六维度评分说明：**
- 每个维度独立评分，范围0-100
- 50分代表平均水平
- 70+分代表优秀水平
- 85+分代表顶尖水平
- 六维度评分**不影响**总ELO评分，仅用于细节能力展示

---

### 4. **评分衰减机制**

为保持选手池的活跃度，系统实施评分衰减：

- **衰减条件**：超过**30天**未参加比赛
- **衰减速率**：每天衰减**0.1分**
- **最低评分**：不会低于**800分**
- **恢复方式**：参加比赛即停止衰减

## 评分系统的关键特性

### 1. **公平性**
- 使用成熟的ELO算法
- 考虑双方实力差距
- 动态K系数避免评分滞后

### 2. **准确性**
- 置信度系统反映评分可靠度
- 六维度分析全面评估能力
- 定级赛快速定位真实水平

### 3. **激励性**
- 初始评分基于LOL段位，公平合理
- 胜利奖励明确，鼓励竞技
- 高评分选手获得更多曝光

### 4. **动态性**
- 评分实时更新
- 长期不活跃会衰减
- 鼓励持续参与比赛

## 常见问题

### Q1: 我不填写段位会怎样？
**A:** 系统会给你1200的默认起始评分，这是标准的中等水平。

### Q2: 我的段位很高，初始评分就高吗？
**A:** 是的！系统会根据你的LOL段位给予相应的初始评分，这样更公平。

### Q3: 如何快速提升评分？
**A:** 多参加比赛并取得胜利！前10场定级赛评分变化最大。

### Q4: 评分会无限上涨吗？
**A:** 不会。高评分选手K系数较低，评分变化较小，需要战胜同等级对手才能继续提升。

### Q5: 长期不打会掉分吗？
**A:** 超过30天不打比赛会开始衰减，但速度很慢（每天0.1分）。

### Q6: 为什么总评分是1500，但六维度都是50？
**A:** 这是两个独立的评分系统！
- **总评分（1500）**：使用ELO系统（0-5000），反映整体实力
- **六维度（50）**：使用百分制（0-100），反映具体能力
- 类比：总评分像"综合成绩"，六维度像"各科分数"

### Q7: 六维度会影响总评分吗？
**A:** 不会直接影响！
- 总评分只看胜负（ELO算法）
- 六维度只看比赛表现数据
- 但六维度高的选手通常胜率也高，所以间接相关

## 技术实现

### 核心组件
1. **PlayerRegistrationUseCase**: 处理选手注册逻辑
2. **RatingUpdateService**: 比赛后更新评分
3. **EloCalculator**: ELO算法实现
4. **SixDimensionAnalyzer**: 六维度数据分析
5. **ConfidenceManager**: 置信度管理

### 数据库表
- `player_profiles`: 存储选手档案和评分
- `matches`: 存储比赛记录
- `match_performances`: 存储选手比赛表现

### 配置文件
- `RatingConfig`: 评分系统配置（K系数、衰减速率等）
- 可按赛区自定义配置

---

## 总结

用户注册选手后，系统会根据LOL段位自动分配合理的初始评分（默认1200）。选手通过参加比赛，系统自动使用ELO算法更新评分，并结合六维度分析全面评估能力。整个过程自动化、公平、透明。

**核心流程：**
```
用户注册 → 填写段位 → 计算初始评分 → 参加比赛 → 上传数据 → 更新评分 → 提升排名
```
